## Casos de uso cubiertos

| UC | Descripción | Permiso |
|---|---|---|
| UC-PAG-001 | Consultar bandeja de garantías (listado paginado) | PAYMENT.READ_LIST |
| UC-PAG-001b | Obtener resumen agregado por estado | PAYMENT.READ_LIST |
| UC-PAG-002 | Ver detalle de garantía con historial de ajustes | PAYMENT.READ_DETAIL |
| UC-PAG-003 | Registrar ajuste append-only (cargo/descuento) | PAYMENT.REGISTER_ADJUSTMENT |
| UC-PAG-004 | Aprobar devolución de garantía | PAYMENT.APPROVE_REFUND |
| UC-PAG-005 | Cerrar expediente financiero | PAYMENT.CLOSE_FINANCIAL |

### Reglas de negocio cubiertas

| BR | Descripción |
|---|---|
| BR-PAG-001 | Una garantía se crea automáticamente al activar un alquiler con depósito |
| BR-PAG-002 | El monto neto es originalAmount + Σ ajustes (pueden ser negativos) |
| BR-PAG-003 | Un ajuste es append-only; no se puede eliminar |
| BR-PAG-004 | La devolución requiere autorización PAYMENT.APPROVE_REFUND |
| BR-PAG-005 | El cierre financiero es irreversible una vez confirmado |
| BR-PAG-009 | Aislamiento multiempresa: companyId + branchId del actor en toda operación |
