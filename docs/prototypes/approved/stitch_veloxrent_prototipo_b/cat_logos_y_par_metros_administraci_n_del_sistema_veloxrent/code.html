Módulo Configuración Global POL-SYS-014 / PARAMS

Ajuste de parámetros operacionales, políticas tarifarias de reserva y control de plantillas contractuales legales de VeloxRent.

Protocolo de Gobernanza de Parámetros (BR-SYS-007): Toda modificación a los montos de garantía o plantillas legales queda registrada con hash criptográfico en la auditoría RIO. Modificaciones sobre reservas aplican exclusivamente a nuevas reservas emitidas con posterioridad a la confirmación de cambio.
