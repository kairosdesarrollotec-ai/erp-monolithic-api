# Responsive visual

Fija viewport, DPR, navegador, fuente, tema, locale, timezone, reloj y fixture. Genera actual/diff/reporte; mide diferencia y revisa estructura, jerarquía, CTA, componentes y tokens. Valida viewports faltantes según UX/UI. Nunca actualiza baselines. `≤2%` no aprueba automáticamente y `>2%` requiere revisión. Produce evidencia y veredicto normativo.
