# Accessibility

Prueba semántica, teclado, foco, nombres accesibles, errores, contraste, 200% zoom, reflow 320 px, reduced motion y lector de pantalla. WCAG prevalece sobre un defecto del JPG/PNG; conserva la intención visual y registra toda diferencia necesaria como desviación justificada. Hallazgos críticos bloquean.
