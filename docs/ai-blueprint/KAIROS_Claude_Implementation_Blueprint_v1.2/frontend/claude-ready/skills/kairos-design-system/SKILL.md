# Design system

Analiza el baseline con `Read` y produce el mapa elemento→componente→variante→token. Reutiliza Radix UI Primitives y tokens UX/UI v3.1. Prohíbe hex, sombras, radios, tamaños o componentes arbitrarios. Si falta un patrón, detiene y solicita decisión UX/UI; los cambios globales requieren pruebas visuales de todos los consumidores.
